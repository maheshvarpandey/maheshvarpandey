## 🚀 Featured Projects

### 🔨 ZipBid — Real-Time Auction Platform
A bidding platform that supports auction management and live bidding workflows for admins, clerks, and bidders.

- Real-time bid synchronization, validation, and outbid notifications
- Auction and lot management, reserve-price enforcement, and winner selection
- Bid history, reporting, user management, and access control
- **Tech:** React, Node.js, Supabase, Tailwind CSS

### 💰 Snbla — Save Now, Buy Later
A savings and rewards platform that helps users save toward a goal and receive rewards when purchasing products.

- Merchant and user wallet management
- Savings and redemption workflows
- **Tech:** React, Node.js, PostgreSQL, Sequelize, Ant Design, Tailwind CSS

### 🤝 ReferUs Network — Referral Management
A platform that helps businesses grow through customer referrals and track referral performance.

- Multi-level administration for referrers, businesses, and super admins
- Referral tracking and engagement analytics
- **Tech:** React, Node.js, MySQL, Sequelize

### 🩺 EGC — Healthcare Management Platform
A healthcare and organizational platform with integrated applications for goal setting, task management, feedback, and analytics.

- Worked across frontend and backend components
- Supported role-based workflows and organizational progress tracking
- **Tech:** MongoDB, Express, React, Node.js, GraphQL

### 📊 Vitals Vault — Health Data & Vitals Tracking
A platform for recording and monitoring health information through dashboards and reports.

- Vitals logging, trend dashboards, reminders, and alerts
- Role-based access and exportable reports
- **Tech:** React, Next.js, TypeScript, Supabase, Tailwind CSS, AWS Amplify

### 🛒 The Auto Parts Shop — E-commerce
An e-commerce platform with vehicle-specific auto-part compatibility features.

- Helped transition the frontend from React to Next.js to improve SEO
- Contributed to frontend leadership and backend development
- **Tech:** React, Next.js, Node.js, GraphQL, Apollo Client, MongoDB
